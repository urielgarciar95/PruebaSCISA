# Mi Proyecto

Proyecto que consume la API de pokemon y muestra el nombre y la imagen en una tabla de resultados.

## Tecnologías

- C#
- ASP.NET MVC
- JavaScript

# Envío de correo  
-En el archivo appsettings.json se configuran las credenciales así como el destinatario en el apartado "DatosCorreo".  
-Se dejó la paginación a 5 registros por pagina, si se requiere cambiar hay que modificar la variable filasPorPagina en el archivo site.js  
-Se tomó la desición de ocultar los botones de exportar a excel y enviar correo hasta que haya información en la tabla de resultados, esto para evitar exportar o enviar archivos vacíos.
